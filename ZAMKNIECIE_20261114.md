# UMUD — finalne profile C1

Rekomendowane finały: C1_F1 0,20486 i C1_F3 0,20494, według wyników podanych przez użytkownika. Faktyczny wybór na koncie Kaggle nie jest potwierdzony w tym repo.

Kod pełnej inferencji i oba presety są w `final/`, runtime w `c1/`, a wszystkie 16 notebooków etapów w `pipeline/`. Zapisane historyczne tabele R96 nie są wejściem C1.

Wagi należy zebrać notebookiem `final/UMUD_WAGI_FINAL_COLAB.ipynb` i dodać jako Dataset do inferencji. Paczka kodu nie zawiera binarnych checkpointów. Publiczne testy używają danych syntetycznych, a prywatne logi i eksporty predykcji pozostają poza repo.
